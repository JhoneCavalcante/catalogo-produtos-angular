# Catálogo de Produtos - Angular

Projeto simples feito em Angular para aprendizado e prática.

## Tecnologias
- Angular
- TypeScript
- HTML
- CSS

## O que o projeto faz
- Mostra uma lista de produtos
- Exibe nome, preço e status
- Indica se o produto está disponível ou não

## Como rodar o projeto

1. Instalar as dependências:
npm install

2. Rodar o projeto:
ng serve

3. Abrir no navegador:
http://localhost:4200

## Objetivo
Projeto criado para estudo e portfólio.
